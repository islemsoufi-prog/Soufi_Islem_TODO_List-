Nom :
To-Do List Interactive

description du projet:

Ce projet est une page web interactive de type To-Do List permettant de gérer des tâches quotidiennes.
L’utilisateur peut ajouter, modifier, supprimer et marquer des tâches comme terminées.
La page inclut également un système de filtrage, une barre de progression pour suivre l’avancement et un mode sombre pour améliorer l’expérience utilisateur.


---

 Technologies utilisées:

* HTML5
* CSS3
* JavaScript 
* localStorage (stockage des données côté navigateur)

---

 Fonctionnalités principales:

* Ajout de tâches
* Modification de tâches
* Suppression de tâches
* Marquage des tâches comme terminées
* Filtrage des tâches (toutes, actives, complétées)
* Compteurs dynamiques (total, actives, terminées)
* Barre de progression
* Mode sombre / clair
* Sauvegarde automatique avec localStorage
* Interface responsive

 Nouveautés explorées:

* Utilisation de localStorage pour sauvegarder les données
* Manipulation du DOM avec JavaScript
* Gestion des événements (click, submit, change)
* Utilisation des variables CSS pour gérer le thème (dark/light)
* Mise à jour dynamique de l’interface sans rechargement de page

---

 Difficultés rencontrées:

* Synchronisation entre les données et l’affichage
* Gestion des filtres dynamiques
* Mise à jour correcte des compteurs et de la barre de progression
* Gestion des événements sur des éléments générés dynamiquement
* Organisation du code pour le rendre lisible et maintenable
* Organisation du code JavaScript

---

 Solutions apportées:

* Utilisation d’un tableau JavaScript pour stocker les tâches
* Re-render de la liste après chaque modification
* Création de fonctions dédiées (render, update, save)
* Utilisation de localStorage pour conserver les données
* Tests progressifs pour vérifier chaque fonctionnalité
